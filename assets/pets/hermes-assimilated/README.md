# Hermes Assimilated v2

A cybernetic Hermes companion with emerald accents and Borg-inspired implants.

Pet adaptation for CollectiveUI by @cl0ud6uru. Inspired by Hermes Agent from Nous Research. Unofficial community artwork; not affiliated with or endorsed by Nous Research.

The user supplied `hermes-assimilated-v2.zip` and requested this as a separate
catalog pet alongside green Hermes. Both runtime files from the updated close-framing
ZIP are preserved byte for byte; the manifest and credit are unchanged.
The [supplied source notice](SOURCE-README.txt) records image generation from the
selected Seven Echo concept, the user-requested close waist-up revision matching
green Hermes, and mechanical atlas assembly. All 73 distinct occupied
frames, sixteen clockwise gaze poses, and fifteen transparent unused cells remain.

This is unofficial Star Trek Borg-inspired fan artwork, not affiliated with or
endorsed by Star Trek's owners or Nous Research. Complete provenance and third-party
licensing permissions for the underlying reference/character have not been
established. This artwork and its reproductions in previews/screenshots are excluded
from CollectiveUI's application MIT license. No ownership transfer or additional
third-party license is asserted; attribution is not a license grant.

The former full-body release remains in public commit
`a235f001722aa6923799fd9386c10f351c38a86b`. On migration/startup, only its exact stored
PNG (`55870bfe41ee25b78a99fc75edffcce39a37abaf4d748a681b14e729d4fa0690`)
under `builtin-hermes-assimilated-v2` is upgraded. The catalog ID, metadata, publication
state and selections stay intact; the raster gets a new revision. Operator-replaced
pixels and private imports are untouched. Existing public sign-in-page consent stays
pinned to the old revision and must be reconfirmed by an admin to display the new one.
